# Inventário financeiro preservado e contratos v1

Versão de cálculo: `atmos-2026-09-v1`. Fontes canônicas: `src/lib/proposalCalcs.ts`, `src/lib/accommodationCalcs.ts`, `ProposalFormDialog.tsx` e SQL `proposal_pricing_from_bundle`. A suíte existente de 593 testes inclui regressões desses caminhos; as regressões SQL/HTTP v1 exercitam sua continuidade financeira. Este inventário descreve comportamento do código, sem constituir nova aprovação comercial/tributária.

## Mudanças deliberadas de compatibilidade

`20261013178000` revoga o CRUD financeiro/filhos e os RPCs antigos save_proposal_bundle,save_proposal_cost_checks,generate_proposal_receivable para authenticated. O frontend atual deve migrar para os comandos v1 no mesmo rollout; os RPCs antigos não são adaptadores silenciosos. As tabelas continuam disponíveis para leitura autorizada. Aprovação pública/Clicksign permanecem com os contratos service_role existentes e testes próprios; a automação financeira nova fica desligada.

D01 marco, D04 comissões, D05 parciais, D06 serviço por dia, D07 hotel simples real, D08 grupos, D09 cancelamento/devolução, D10 plano/layout contábil, D11 fechamento/datas, D12 bancos/agrupamentos e D14 delegação continuam decisões da Atmos/Gustavo. O código implementa validações, modos exatos e bloqueios tipados; o cenário sintético registra políticas identificadas como SYNTHETIC e não autoriza ativação comercial.
